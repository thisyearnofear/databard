# ChatGPT plugin — starter prompts (directory listing)

Use these as **Example Prompts** on the ChatGPT plugin directory card. Phrases match how users ask — not internal product jargon.

## Primary

1. Is my data healthy?
2. How healthy is our sales schema?
3. Give me a quick data health score for the demo catalogue.

## Supporting

4. Any stale or ownerless tables I should worry about?
5. Score this DataHub dataset for health issues.
6. Before the exec review, sanity-check our catalogue health.

## Do not put on the listing

- Checkout / pricing / “buy a briefing” prompts
- x402 / wallet payment prompts
- Write-back or Probe / marketplace ranking prompts (not in the ChatGPT free tool set)

For eval coverage beyond the listing, see [CHATGPT_PLUGIN_EVAL.md](./CHATGPT_PLUGIN_EVAL.md).
